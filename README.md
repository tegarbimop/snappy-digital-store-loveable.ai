# Digital Haven

Buatkan website toko online produk digital (seperti e-book, course, dan template) dengan desain modern dan minimalis

Fitur Utama:
- Homepage interaktif dengan headline menarik, penjelasan produk, dan tombol panggil tindakan (CTA)
- Halaman katalog produk lengkap dengan contoh minimal 3 produk digital, harga, dan tombol beli (dummy)
- Bagian testimoni atau ulasan pembeli untuk meningkatkan kepercayaan
- Formulir kontak dan halaman bantuan dasar untuk pelanggan

Desain & Tampilan:
- Tampilan responsif yang optimal untuk perangkat mobile maupun desktop
- Mendukung mode gelap (dark mode) secara bawaan
- Struktur kode bersih dan modular agar mudah dikembangkan lebih lanjut
